How to use
  • Drag the image to move it. Once it has a control point, or when you're zoomed in so far that none of its corners are in view, dragging the image pans the map instead.
  • Drag a corner to scale and rotate. Hold Shift to scale without rotating. The corners lock once there's a control point.
  • ⌘/Ctrl-click the image to add a control point. Do it again on a point to remove it.
  • Drag a control point to pin that spot of the image to a new place on the map. The image warps to fit.
  • Export saves the warped image, north-up. PNG and GeoTIFF are in Web Mercator; KMZ opens in Google Earth. The placement and control points are stored inside, so dropping the file back on the map puts it in the same place.
