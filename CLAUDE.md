# rubbersheet

A static site with no build step: `index.html`, `style.css` and ES modules in `js/`. Tests run with `node --test test/warp.test.mjs`.

## Pull requests

Start every PR description with a link for trying the branch in a browser:

    **Try it:** https://raw.githack.com/e-n-f/rubbersheet/<branch>/index.html (if a change doesn't show up, use ⌘⇧R to reload)

with `<branch>` replaced by the PR's head branch name, slashes and all (for example `claude/some-branch`).
